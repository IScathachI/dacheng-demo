# dacheng-demo — 大成新华演示站

北京大成新华认证咨询有限公司网站原型。纯 HTML / CSS / JavaScript，无需安装或编译，不依赖境外 CDN。**本站为本地演示版，所有内容均为样例。**

## 预览方式

直接用浏览器打开根目录 `index.html`，或在项目目录启动任意静态服务器后访问。所有资源与链接均为相对路径，可部署到 GitHub Pages 的 `/dacheng-demo/` 子路径。

## 页面与路由

| 页面 | 地址 |
|---|---|
| 首页 | `index.html` |
| 服务总览 / 详情 | `services.html`、`service.html?id=green｜system｜manage｜vocs｜train`（锚点 `#process` 服务流程、`#deliver` 交付物） |
| 案例 / 详情 | `cases.html?topic=green｜system｜manage｜vocs`、`case.html?id=demo-green` 等 |
| 新闻 / 详情 | `news.html?topic=green｜vocs｜system｜event｜assoc｜notice`、`article.html?id=demo-n1` 等 |

| 联系我们 | `contact.html`（`#form` 在线留言） |

| 公众号菜单对照 | `wechat-menu.html` |

`?topic=` 未知值时回退为“全部”；筛选支持直接打开与刷新。

代码结构：

- `css/main.css`：全站样式（设计变量、排版、布局、组件、各页面模块，文件顶部有目录）。
- `css/motion.css` + `js/motion.js`：独立的动效模块（进入、标题分行、文字分段点亮、轻视差）。两个文件可以整体移除，页面内容不受影响。
- `js/main.js`：页头页脚、弹窗、内容数据、列表/详情渲染、筛选、表单与会员演示逻辑；不依赖 `motion.js`。
- `css/hero-fx.css` + `js/hero-fx.js`：首页首屏主视觉的增强效果（网点粒子成像、玻璃带光泽、闪光点与微光尘、暂停按钮），只在 `index.html` 加载。
- `css/flip.css` + `js/flip.js`：首页五类服务的翻牌，只在 `index.html` 加载；卡片结构由 `js/main.js` 的 `svcFlip()` 生成。
- `css/decor.css` + `js/dot-fall.js`：首屏以下的版面点缀（关键词走马灯、大图局部、描边编号、半调网点纹理、网点飘落分隔条）。`decor.css` 全站加载，`dot-fall.js` 只在首页和关于页加载。
- `assets/hero-paper-glass-v3.jpg`：首屏原创抽象纸张与玻璃图片（1672×941，242,192 字节，约 237 KiB），本地加载。同目录的 PNG 是源文件，网页不引用。

## 界面与动效（2026-11 改版）

纸白 / 炭黑 / 灰为基础，品牌蓝只作重点色，浅蓝辅助背景只用于流程等个别面板。首页与关于页为大标题、原创 SVG 视觉、编号服务行、带封面的案例卡片、紧凑资讯列表；其余页面共用同一套导航、页脚、标题区、列表、详情、按钮与表单样式。不引入任何外部库、远程字体或构建步骤。

动效通过 HTML 上的 `data-*` 属性声明，由 `js/motion.js` 读取：

| 属性 | 作用 |
|---|---|
| `data-reveal`（可选值 `fade`、`clip`） | 单个元素进入；`clip` 用于大图的裁切展开 |
| `data-reveal-group` | 其直接子元素依次进入（列表被筛选重新渲染后同样生效） |
| `data-split` | 标题逐行进入，行用 `<span class="ln">` 标出，不标则整体作为一行 |
| `data-scrub` | 文字分段随滚动点亮，段用 `<span class="seg">` 标出 |
| `data-parallax="0.06"` | 很轻的装饰性视差，仅桌面精确指针设备 |
| `data-delay="120"` | 额外延迟（毫秒） |

安全约定：内容默认可见。只有脚本成功运行、浏览器支持 IntersectionObserver、且用户未开启“减少动效”时，才给 `<html>` 加 `.motion-ok` 并启用进入前的隐藏状态；初始化出错或 3 秒内未完成会自动撤销。不劫持滚动、不替换鼠标指针、无声音；只有首页有一段可随时跳过的开场（见下文“首页开场”），其他页面没有。任意页面地址加 `?motion=off` 可以以无动效状态打开，便于整页截图核对内容。

## 第三版增强：首屏光效、粒子与服务翻牌

在第二版基础上叠加，三个模块都可以单独移除，移除后页面回到静态图片与静态卡片。

**首屏主视觉**（`index.html` 的 `figure[data-hero-fx]`）

- 默认是**全屏版**（`<section class="hero hero--full">`，860px 以上）：图片面板铺满首屏，大标题叠在左上，导语与入口是左下的一张磨砂卡片，“说明”是贴在面板底边的一条磨砂条，右下有“继续浏览”锚点链接。面板高度、标题字号和留白都按视口高度计算：视口高度约 680px 以上（含 1280×720、1366×768）时，整块面板连同底边说明条都在首屏内；窗口再矮时面板按内容自动加高，页面照常向下滚动，文字和入口不会互相遮挡。更窄时上文下图，图片紧跟在入口按钮之后，高度约占半屏。
- 去掉 `hero--full` 这个类，就回到第三版最初的“图文并列”版式（左文右图），其余结构、样式和脚本都不用改。
- 全屏版里文字叠在图上：带 `data-fx-avoid` 的文字块（标题、导语卡片）下方的网点动得更少，闪光点和微光尘在那里几乎隐去；标题背后另有一层很淡的纸色柔光保证对比度。
- 入场时面板从画面中部的小窗口展开到铺满首屏，标题逐行跟上。
- **网点粒子成像**（2026-11-15 起替换了原来跟随鼠标的“玻璃放大镜”）：`js/hero-fx.js` 读取图片里的蓝色印刷网点，拆成粒子（大屏桌面约 1.7 万个，另有约 900 个闪光点、500 个微光尘；手机约 7–9 千个），全部用原生 WebGL 在 GPU 上计算。画面**自己动，不跟随鼠标**：
  - 入场：网点从画面左侧流入，按从左到右的顺序落到各自位置拼出图案，像被印刷辊印上去（约 2.8 秒）；
  - 原位漂动：每颗网点沿小圈缓慢游动；
  - 印刷波：每隔约 6.5 秒有一道斜向的波扫过，经过的网点被掀起、放大、泛出青蓝色，再落回原处；
  - 飘散：约 12% 的网点周期性脱离纸面，沿纸张走势飘出一段后淡出，再在原位重新出现；
  - 玻璃带自己流动：轻微的液态折射与色散，蓝青—淡紫的虹彩沿玻璃流转；玻璃高光处有闪烁的光点，画面里有少量缓慢上浮的微光尘；一条柔和的高光带每隔几秒扫过整幅图；
  - 向下滚动时，网点散开并向下飘落、变淡（图片上边接近视口顶部后才开始，手机上把图片滚到屏幕中间时不会散开）；紧接着首屏下方的第一条“网点飘落分隔条”把它们接住。
- “暂停动效 / 开启动效”按钮：全屏版里在面板**右上角**、图注下方（左上角是标题）；并列版式和窄屏上文下图时在图片左上角。可用键盘操作，选择在当前标签页会话内记住。

**服务翻牌**（`index.html` 的 `#svc-grid[data-view="flip"]`）

- 正面是编号、图标和名称，背面是简短介绍、“了解详情”链接和“翻回正面”按钮。翻面按钮和详情链接是两个独立控件。
- 点“查看简介”或卡片空白处翻面；键盘用 Tab + Enter/空格，焦点在翻开的卡片内时按 Esc 翻回；触屏点按即可。桌面悬停时卡片会轻微倾斜并掀起一角。
- 背对用户的一面加了 `inert`、`aria-hidden` 并设为 `visibility:hidden`，其中的链接和按钮不会被 Tab 到。
- 服务总览页 `services.html` 仍是编号行，便于整页扫读；把它的 `#svc-grid` 也加上 `data-view="flip" data-flip-grid` 并引入 `flip.css` / `flip.js` 即可切换成翻牌。

**关闭、暂停与回退**

| 情况 | 结果 |
|---|---|
| 系统“减少动效”、地址带 `?motion=off`、`DCMotion.disable()`（含运行中途） | 不创建或立即拆除画布与按钮，只剩静态图片；翻牌变成把两面内容都展开的静态卡片，详情链接直接可见 |
| 点“暂停动效”、标签页隐藏、主视觉滚出视口 | 停止逐帧绘制，画布保留最后一帧；恢复后从原处继续 |
| 图片加载失败 | `figure` 加 `.is-fallback`、`section` 加 `.has-fallback`，显示第二版的深色 SVG 构图，全屏版里叠在上面的标题改为浅色，不启动任何效果 |
| WebGL 不可用、中途丢失，或读不到图片像素（如直接双击打开的 `file://` 页面） | 改用纯 CSS 的虹彩光泽，加 110 个 2D 小粒子（手机 40 个），没有网点成像 |
| 连续掉帧 | 先把画布分辨率降到约 2/3 并少画 40% 的网点，仍然掉帧则放弃 WebGL |
| 任一模块脚本没加载或出错 | 该模块不生效，文字、图片、链接不受影响 |

性能约束：设备像素比上限 1.5（手机 1.25），画布长边上限 1680 像素（原图宽度）；不监听鼠标，布局只在滚动/缩放后的下一帧读一次。

复查接口（浏览器控制台）：`DCHeroFx.state()` 返回当前状态（含模式、各类粒子数、滚动进度）；`DCHeroFx.renderAt(秒)` 把效果时间推进到指定时刻并立即画一帧，只用于核对画面，不代表实际播放；`DCFlip.isActive()` 返回翻牌是否启用。

## 版面点缀：首屏以下不再“干”（2026-11-15）

只用现有的一张主视觉图（浏览器已缓存，不增加下载量）和纯 CSS 图形，不新增素材、不编造数据。样式在 `css/decor.css`（全站加载），分隔条动画在 `js/dot-fall.js`（首页与关于页加载）。

- **关键词走马灯**（首页首屏下方）：两条横向自动滚动的关键词带，大的一条是五类服务名称（实心、描边、蓝色交替，中间用半调小网点分隔），小的一条反向滚动，是服务环节（标准宣贯、差距分析、记录与台账等，中间用 CMYK 色标分隔）。读屏软件读的是一行普通文字；鼠标悬停时停下。
- **大图局部穿插**：首页“公司介绍”左栏一张竖幅局部（蓝色墨浪），联系区蓝底上叠一张单色化的局部；每个内页标题区下方加一条图片横幅（由 `js/main.js` 插入，各栏目取图片不同位置）。都带轻微视差、裁切角标和 CMYK 色标。
- **印刷元素点缀**：首页各区块右上角的大号描边编号（01–05）；流程区右上角一片缓慢斜向流动的半调网点；案例区左下角的网点；案例封面与“服务对象”条上的 CMYK 色标；页脚大字“大成新华”用网点填充。
- **网点飘落分隔条**（首页 4 条、关于页 1 条）：分隔条第一次滚进视口时，几百颗网点从上方落下、弹一下，从左到右落定成四行半调网点，再有一道波扫过一次，然后静止（每条只播一次，约 2–3 秒）。首页第一条紧接首屏，接住首屏向下飘落的网点。
- **暂停**：首屏“暂停动效”按钮现在对整页生效：给 `<html>` 加 `.fx-paused`，走马灯、流程区网点和正在播放的分隔条一起停下。
- **关闭与回退**：`?motion=off`、系统“减少动效”、`DCMotion.disable()` 时，走马灯和网点纹理不动，分隔条显示为一条静态网点带；图片横幅、配图照常显示。

## 首页开场、服务封面与流程时间轴（2026-11-15）

三个模块都可以单独移除，移除后回到上一版的样子。没有新增图片素材，没有编造数据。

**首页开场**（`css/intro.css`、`js/intro.js`，只在 `index.html` 加载，脚本必须放在 `<head>` 里、`motion.js` 之后）

- 打开首页时，上千颗印刷网点（大部分品牌蓝，少量炭黑和 CMYK 色点）从画面四周飞来，从左到右落定，拼出“大成新华”四个字；字下方浮出 CMYK 色标和“北京大成新华认证咨询有限公司”。字形落定后，每隔约 2.2 秒有一道波光从左到右扫过字面。
- **互动**：鼠标（触屏是手指）划过时，附近的网点被拨开，离开后像弹簧一样慢慢弹回原位。正在拨动时开场会多停留一会儿。
- **退场**：不操作约 3.6 秒后自动退场，拨动时最长约 8 秒。单击或轻点任意处、滚动滚轮、按任意键、点右上角“跳过开场”都会立即退场：网点向下散落、遮罩淡出，同时首屏主视觉开始入场。用来跳过的空格、方向键、滚轮不会让页面滚走，退场后停在首屏顶部。
- **什么时候不播放**：
  - 系统“减少动效”、地址带 `?motion=off` 或 `?intro=0`、动效被关闭；
  - 地址带锚点（如 `index.html#services`）；浏览器前进 / 后退；从本站其他页面点链接回首页；
  - 页面在后台标签页打开。
  - 刷新首页或从站外打开时播放；地址加 `?intro=1` 可强制播放，便于演示。
- **安全**：
  - 决定播放时先给 `<html>` 加 `.intro-on`，用纸色盖住页面，避免闪一下；
  - 出错、或 9 秒内没有正常结束，会立即移除遮罩；
  - 首屏的 `motion.js`、`hero-fx.js` 会等到开场结束（`dc:intro-done` 事件）再开始入场，两段动画不会叠在一起。
  - 窄屏（< 560px）的字号占比略大、网点更细，保证“成”“新”这类多笔画的字在手机上也能看清。
- 复查接口：`DCIntro.state()` 返回当前状态（阶段、网点数、网点间距、最大拨开距离）；`DCIntro.skip()` 立即退场。

**服务卡片封面**（`js/main.js` 的 `svcFlip()` 与 `FLIP_COVER`，样式在 `css/flip.css`）

- 首页五张服务翻牌的正面顶部各加一张封面。用的都是主视觉图，但每张卡放大的倍数和取景位置不同（`FLIP_COVER` 里的 `[放大倍数, 取景位置]`），所以五张封面看起来各不相同。
- 封面左上角有 CMYK 色标，底部用白色网点过渡到卡片。悬停或键盘聚焦时图片再放大一点、染上品牌蓝。
- 封面是装饰图（`alt=""`、`aria-hidden`），不影响读屏和翻牌的键盘操作；动效关闭时它照常显示，只是不放大。

**服务流程时间轴**（`index.html` 的 `ol.steps[data-steps]`、`js/steps.js`、`css/decor.css` 第 08 节）

- 五个步骤改成带图标的白色卡片，图标是原创线条 SVG：沟通诊断、差距分析、方案与辅导、自查预审、对接与改进。
- 桌面上卡片上方有一条横向进度线。随着页面向下滚动，蓝线从左向右走，走到哪一步，那一步就点亮：卡片变白、上浮、出阴影，图标变成实心蓝底。还没走到的步骤是淡化的描边样式。
- 平板（≤1080px）不显示进度线；手机（≤640px）改成一列横向卡片，图标在右侧，同样随滚动逐个点亮。
- `?motion=off`、系统“减少动效”、`DCMotion.disable()` 或脚本没加载时，五步全部以点亮状态静态显示，内容一样完整。

### 本轮复测（2026-11-15，开场 / 封面 / 流程）

内置浏览器面板显示状态、真实动画帧下观察（模拟视口，不是真机）：

- **开场**：
  - 1280×720 下打开后 2.4 秒截图时字形已拼好、公司全称已浮出，网点间距 9px；
  - 375×812 下网点间距 4px、937 颗。修正前是 5px、501 颗，“成”“新”的笔画糊在一起；
  - 真实鼠标划过时网点最大被拨开约 62px，随后弹回；
  - 单击、空格、滚轮都能退场，空格和滚轮退场后 `scrollY` 仍为 0；
  - 退场后遮罩和 `.intro-on` 都已移除，首屏网点粒子接着入场（`DCHeroFx.state()` 显示 built / running）。
- **不播放的情况（已实测）**：从 `services.html` 点链接回首页、`index.html#services`、`?motion=off&intro=1`；地址栏直接打开时播放。
- **流程时间轴**：
  - 1200×1086 下滚动过程中进度依次为 0 → 0.51（前三步点亮）→ 1（五步全亮）；
  - 375×812 下进度 0.47 时前三步点亮；
  - `?motion=off` 下五步不透明度都是 1，没有淡化。
- **服务封面**：1200×1086 与 375×812 下五张封面取景各不相同，没有遮挡文字。
- **回归**：16 个页面组合 × 1440×900 / 1280×720 / 768×1024 / 375×812，共 64 组，没有横向溢出；首页测试过程中控制台没有报错。

- 浏览器前进 / 后退不播放：逻辑已写，但没有单独实测；
- Safari、Firefox，以及系统级“减少动效”的真实开关。

## 历次复测记录

### 网点粒子版复测（2026-11-15）

在内置浏览器面板显示状态下、视口模拟 1440×900 与 375×812、真实动画帧下观察：

- 入场：重载后约 0.7–1.5 秒内能看到网点云从左侧流入并逐步拼成图案；
- 印刷波：经过时可以看到一条放大、泛青的网点带，过后复原；
- 滚动：滚动 300px 时网点明显向上散开，回到顶部后复原（之后已改为散开后**向下**飘落，接到下方的网点分隔条）；
- 帧间隔（1440×900，约 1.8 万个粒子）：5 秒内 1201 帧，最大 4ms，没有超过 33ms 的帧；手机模拟（约 7700 个粒子）3 秒内最大 4ms；
- 暂停/恢复（真实点击）、`?motion=off`、运行中途 `DCMotion.disable()`、图片加载失败、无 WebGL、读不到图片像素这几条路径都按上表的结果工作；
- 9 个页面组合在 1440×900、1280×720、768×1024、375×812 下无横向溢出。
- 上一节提到的约 2.5 秒停顿已查明：是测试期间浏览器面板被短暂隐藏（页面报告 `hidden`），效果按设计停止绘制，面板恢复显示后继续。
- 未覆盖：普通浏览器整窗下的人工目视、真机手机与触控、Safari/Firefox、系统级“减少动效”的真实开关。

### 复测记录（2026-11-15，交接前收尾）

本轮没有新增功能，只修了一处版式问题并补做了实际播放下的观察。

- **修复**：1280×720 下全屏面板超出首屏 20px、底边说明条被裁掉。改为在视口高度不足 780px 时收紧标题字号、间距和卡片内边距。复测 1280×720（面板下边 711，余 9px）和 1366×768（下边 760，余 8px）均完整落在首屏内，文字块互不遮挡；1280×640 及更矮的窗口会超出（3–86px），此时面板自动加高、页面可滚动，两个入口按钮仍在首屏内。
- **实际播放**（内置浏览器面板处于显示状态、视口模拟 1440×900、真实动画帧采样，未使用 `renderAt`）：
  - 入场：面板裁切从内缩 24%/20% 在约 1.4 秒内连续展开到铺满，标题三行依次升起，卡片与说明条随后淡入；这段时间帧间隔中位数 6.2ms、最大 11ms。

  - 翻牌：真实点击后约 0.7 秒翻到背面，悬停倾斜与移出复位正常。
- **如实记录的限制**：
  - 以上是嵌在桌面应用里的面板、缩放显示的模拟视口、单台机器的采样结果，没有人在旁边目视观看；不能据此声称在其他设备上流畅。
