# dacheng-demo — 大成新华演示站

北京大成新华认证咨询有限公司网站原型。纯 HTML / CSS / JavaScript，无需安装或编译，不依赖境外 CDN。**本站为本地演示版，所有内容均为样例。**

## 预览方式

直接用浏览器打开根目录 `index.html`，或在项目目录启动任意静态服务器后访问。所有资源与链接均为相对路径，可部署到 GitHub Pages 的 `/dacheng-demo/` 子路径。

## 页面与路由

| 页面 | 地址 |
|---|---|
| 首页 | `index.html` |
| 服务总览 / 详情 | `services.html`、`service.html?id=green｜system｜manage｜vocs｜train`（锚点 `#process` 服务流程、`#deliver` 交付物） |
| 案例 / 详情 | `cases.html?topic=green｜system｜manage｜vocs`、`case.html?id=demo-green` 等 |
| 新闻 / 详情 | `news.html?topic=green｜vocs｜system｜event｜assoc｜notice`、`article.html?id=demo-n1` 等 |
| 课程培训 | `training.html` |
| 标准化资料 / 下载中心 | `resources.html?topic=green｜vocs｜system｜train` |
| 关于我们 | `about.html`（`#intro` 大成简介、`#footprint` 我们的足迹） |
| 联系我们 | `contact.html`（`#form` 在线留言） |

`?topic=` 未知值时回退为“全部”；筛选支持直接打开与刷新。

代码结构：`css/main.css` 样式；`js/main.js` 页头页脚、弹窗、内容数据、筛选、表单与会员演示逻辑。

## 已实现功能

- 响应式布局，手机导航可展开；键盘焦点可见，弹窗支持 Esc / 关闭按钮 / 焦点循环，客服弹窗关闭后焦点回到可见元素。
- 首页完整内容区块；服务、案例、新闻、资料的列表、详情与专题筛选。
- 案例卡片按“需求 / 服务过程 / 预期交付”纵向展示。
- 原创 SVG 视觉，无外部图片；顶部可关闭的演示提示条与页脚说明。

## 仅模拟的功能

- 在线留言、课程报名：基础校验后提示“仅演示，内容未发送”。
- 在线客服：预设问答，非真实客服。
- 会员注册 / 登录 / 专享：不接数据库或微信授权。
- 资料获取：仅弹出“资料待提供”。
- 案例、新闻、课程均为标注“演示内容”的虚构样例。
